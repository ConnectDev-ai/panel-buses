```jsx
<Logo lockup="connect" darkMode size={32} />
```

`lockup`: `connect` (default) · `divemotor` (DIVEMOTOR Connect endorsement) · `ai` (sub-brand) · `wordmark` (type only). Use `darkMode` on navy or gradient surfaces; never recolour the mark by hand.
